# 🎵 WAVELY - Registration Page

## 📝 Project Description
This project is a registration landing page for a fictional music streaming app. It was developed as a practical exercise for the **Epicode Full Stack AI Development Master Pre-course**.

To make the experience more realistic and engaging, I created a custom brand identity, complete with a fictional app name and an original logo.

## 🎯 Challenge Requirements Met
The core of the project is a fully structured web form designed to collect user data. Each field has been implemented using the appropriate HTML5 attributes and input types:

* **First Name:** Input field (`type="text"`)
* **Last Name:** Input field (`type="text"`)
* **Email Address:** Input field (`type="email"`)
* **Password:** Input field (`type="password"`)
* **Date of Birth:** Input field (`type="date"`)
* **Phone Number:** Input field (`type="number"`)
* **Musical Tastes:** Multiple choice selection for favorite genres (`type="checkbox"`)
* **Terms & Conditions:** Acceptance toggle (`type="radio"`)
* **Submit Form:** Submit button (`type="submit"`) labeled *"Invia registrazione"* (Send Registration).

## ✨ Additional Features & Customizations
* **Custom UI (Aesthetics):** Styled with CSS to simulate the sleek and modern look of a real music streaming platform.
* **Fictional Branding:** Integration of an original logo and a catchy app name to give the project a unique identity.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure and built-in validation of the input fields.
* **CSS3:** Custom styling, layout positioning, and branding implementation.
